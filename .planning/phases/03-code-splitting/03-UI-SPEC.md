### PageSkeleton Design

The `PageSkeleton` component is the only new visual element in this phase. It is a composition of the existing `Skeleton` primitive with no new dependencies.

**Structure:**
```
<div animate-pulse space-y-6 py-4>
  <div>                          <!-- Title skeleton -->
    <Skeleton h-8 w-1/3 rounded-md>
  </div>
  <div space-y-4>               <!-- Content block skeletons -->
    <Skeleton h-24 rounded-lg>
    <Skeleton h-24 rounded-lg>
    <Skeleton h-24 rounded-lg>
  </div>
</div>
```

**Visual specifications:**
- Outer container: `py-4` (16px top/bottom), `space-y-6` (24px between sections)
- Title skeleton: `h-8` (32px height), `w-1/3` (33% width), `rounded-md` (6px radius)
- Content skeletons: `h-24` (96px height), `rounded-lg` (8px radius), `space-y-4` (16px gap)
- Animation: `animate-pulse` (Tailwind built-in, 2s opacity pulse)
- Background: `bg-secondary` via `Skeleton` primitive -- `hsl(150 18% 93%)` in light mode
- Accessibility: `aria-hidden="true"` inherited from `Skeleton` primitive
- Responsive: Full width by default, contained by parent `<main>` max-width

**No minimum delay.** Per CONTEXT.md Claude's Discretion, no minimum display delay is added. Skeleton appears immediately on Suspense activation and disappears instantly when content resolves. On fast connections the flash is acceptable because the skeleton is visually subtle (light gray blocks with gentle pulse).

## Layout Integration

The `<Suspense>` boundary placement in Layout.tsx:

```
<main className="flex-1 max-w-4xl mx-auto px-4 py-6 pb-24 w-full">
  <Suspense fallback={<PageSkeleton />}>
    <Outlet />
  </Suspense>
</main>
```

- Suspense wraps only `<Outlet/>` -- sidebar, header, and nav remain eagerly rendered
- Error boundaries (from Phase 2) sit outside Suspense via react-router `errorElement`
- Layout, Sidebar, Header, Navigation are never lazy-loaded (always eager)
