## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card internal padding |
| lg | 24px | Section header bottom margin, card gaps within section |
| xl | 32px | Inter-section gaps |

- Card image banner: h-40 (160px) -- per CONTEXT.md D-02, 25% taller than PathCard h-32

## Component Inventory

### PracticeModeCard (NEW)

Replaces ModeCard in PracticeHubPage context. Adapts PathCard image-banner pattern for practice modes.

**Structure:**
```
<button> (outer container)
  <div> (image banner -- h-40, full-bleed, overflow-hidden)
    <img> (mode image, object-cover, group-hover:scale-105)
    OR (on imgError)
    <div> (gradient fallback: bg-gradient-to-br from mode-soft to mode, centered Lucide icon)
  </div>
  <div> (content area -- p-4)
    <span> (mode label -- font-semibold text-base, mode color)
    <p> (mode description -- text-sm text-muted-foreground, mt-1)
    <p> (mode example -- text-xs italic, mode color, mt-2, "Ex: " prefix)
  </div>
</button>
```

**Props:** `{ mode: PracticeMode; onClick: () => void; className?: string }`

**Styling:**
- Outer: `w-full text-left rounded-xl border border-border bg-card overflow-hidden transition-all duration-200 card-hover card-hover-border focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 cursor-pointer group relative`
- Image banner: `h-40 w-full overflow-hidden bg-muted`
- Image element: `w-full h-full object-cover group-hover:scale-105 transition-transform duration-300` with `loading="lazy"`
- Fallback gradient: `bg-gradient-to-br` from `hsl(var(--mode-{colorVar}-soft))` to `hsl(var(--mode-{colorVar}))`, centered icon at `w-8 h-8` in white
- Content padding: `p-4` (16px)
- Content title color: `hsl(var(--mode-{colorVar}))` via inline style
- Example text color: `hsl(var(--mode-{colorVar}))` via inline style, with opacity ~80% for subtlety

**State management:**
- `useState(false)` for `imgError` -- tracks image load failure
- `onError={() => setImgError(true)}` on img element

**Accessibility (VIS-03):**
- `<button>` element -- natively focusable, activatable with Enter/Space
- `aria-label` with value: `"{mode.label}: {mode.description}"` -- descriptive for screen readers
- `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` -- visible focus indicator
- All information visible on card (no hover required, no tooltip needed)

### Section Headers (REVISED)

Two sections replace current three. Header style at Claude's discretion per D-08.

**Sections:**
1. "Pratica Solo" -- modes: phrases, texts, situations, scripts, visual (5 modes)
2. "Ao Vivo" -- modes: simulation, trails (2 modes)

**Header styling recommendation** (matches existing app pattern):
```
<div className="flex items-center gap-2 mb-4">
  <div className="w-2 h-2 rounded-full bg-primary" />
  <span className="text-xs font-semibold uppercase tracking-wider text-muted-foreground">
    {sectionTitle}
  </span>
</div>
```
Note: Section dot uses `bg-primary` (brand teal) for both sections -- neutral since each card already has its own mode color. This avoids picking one mode color as section representative.

### Mode Grouping (config change)

New exported arrays in `src/config/modes.ts`:
- `soloModes`: phrases, texts, situations, scripts, visual
- `liveModes`: simulation, trails

Or inline grouping in PracticeHubPage (at executor discretion per CONTEXT.md D-07).

## Layout Specification

### Page Layout
```
<div className="space-y-8 pb-20">
  <!-- Page header (existing, unchanged) -->
  <div>
    <h1>Praticar</h1>
    <p>Escolha como quer praticar hoje</p>
  </div>

  <!-- Section: Pratica Solo -->
  <section>
    <section-header />
    <div className="flex flex-col gap-3">  <!-- gap-3 = 12px between cards -->
      {soloModes.map(mode => <PracticeModeCard />)}
    </div>
  </section>

  <!-- Section: Ao Vivo -->
  <section>
    <section-header />
    <div className="flex flex-col gap-3">
      {liveModes.map(mode => <PracticeModeCard />)}
    </div>
  </section>
</div>
```

### Card Dimensions (per CONTEXT.md D-01, D-02)
- Width: full container width (single column)
- Image banner: h-40 (160px), full bleed (no rounded corners on image container top)
- Content area: p-4 (16px padding), ~80px estimated height (title + description + example)
- Total card height: ~240px (160px image + ~80px content)
- Border radius: rounded-xl (12px, matching PathCard)
- Card gap: gap-3 (12px) between cards within section
- Section gap: space-y-8 (32px) between sections

### Visual Distinction from PathCard (VIS-02)
| Property | PathCard | PracticeModeCard |
|----------|----------|------------------|
| Image height | h-32 (128px) | h-40 (160px) -- 25% taller |
| Layout | Grid (sm:grid-cols-2) | Single column |
| Card element | `<div>` | `<button>` |
| Fallback | Emoji text on muted bg | Lucide icon on gradient bg |
| Progress bar | Present | Absent |
| Content density | title + subtitle | title + description + example |
