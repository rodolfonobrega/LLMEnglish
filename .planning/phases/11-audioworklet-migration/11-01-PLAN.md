**Part A: Create the AudioWorklet processor file.**

Create `public/worklets/pcm-processor.js` as plain JavaScript (NO imports, NO exports, NO TypeScript). This file must:

1. Define `class PCMProcessor extends AudioWorkletProcessor`
2. In constructor: initialize `_buffer` as `new Float32Array(4096)`, `_writeIndex = 0`, `_targetSize = 4096`. Listen on `this.port.onmessage` for `{ type: 'configure', bufferSize }` messages to dynamically change the target buffer size (AW-05). On receiving this message, reallocate `_buffer` to the new size and reset `_writeIndex = 0`.
3. In `process(inputs, _outputs, _parameters)`:
   - Get channel data from `inputs[0][0]` (with null guard: if `!inputs[0] || !inputs[0][0]`, return true)
   - Copy each sample from channelData into `_buffer[_writeIndex++]`
   - When `_writeIndex >= _targetSize`: convert the full buffer to PCM16 using the clamping pattern from openaiRealtimeLive.ts: `const s = Math.max(-1, Math.min(1, this._buffer[j])); pcm16[j] = s < 0 ? s * 0x8000 : s * 0x7FFF;` (AW-04, robustness for NaN/out-of-range)
   - Post via Transferable for zero-copy: `this.port.postMessage({ audio: pcm16.buffer }, [pcm16.buffer])`
   - Allocate a new buffer: `this._buffer = new Float32Array(this._targetSize); this._writeIndex = 0;`
   - Return `true` to keep the processor alive
4. Register: `registerProcessor('pcm-processor', PCMProcessor);`

**Part B: Migrate geminiLive.ts startMicrophone() to AudioWorkletNode.**

1. Change the `processor` field type from `ScriptProcessorNode | null` to `AudioWorkletNode | null` (line 72).
2. Remove the `createPcmBlob` helper function entirely (lines 50-59). The PCM16 conversion now happens in the worklet.
3. In `startMicrophone()` (lines 228-254), replace the ScriptProcessorNode block with:
   a. Keep existing: getUserMedia, create AudioContext at 16000Hz, resume(), createMediaStreamSource()
   b. Add: `await this.inputAudioCtx.audioWorklet.addModule('/worklets/pcm-processor.js');` (MUST come after resume() -- see Pitfall 4 in research)
   c. Create: `this.processor = new AudioWorkletNode(this.inputAudioCtx, 'pcm-processor');`
   d. Configure default buffer size: `this.processor.port.postMessage({ type: 'configure', bufferSize: 4096 });`
   e. Handle audio data from worklet via `this.processor.port.onmessage = (event) => { ... }`:
      - Guard: `if (!this.isStreaming || !this.session) return;`
      - Get PCM16 buffer: `const pcm16Buffer = event.data.audio;` (this is a transferred ArrayBuffer)
      - Encode to base64: `const base64 = encodeBase64(new Uint8Array(pcm16Buffer));`
      - Send to Gemini: `this.session.sendRealtimeInput({ media: { data: base64, mimeType: 'audio/pcm;rate=16000' } });`
   f. Connect nodes: `this.sourceNode.connect(this.processor); this.processor.connect(this.inputAudioCtx.destination);`
   g. Set `this.isStreaming = true;`
4. `stopMicrophone()` (lines 256-274) stays the same -- it already calls `this.processor.disconnect()` and `this.inputAudioCtx.close()`, which properly stops the AudioWorkletNode.
5. **DO NOT TOUCH** anything in `scheduleAudioPlayback()`, `stopAllAudio()`, `handleMessage()`, `connect()`, `sendTextMessage()`, or `disconnect()` (AW-06).
