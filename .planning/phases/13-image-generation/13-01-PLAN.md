<objective>
Fix the client-side option forwarding gap in the AI proxy layer.

Purpose: The `generateImage` function in `aiProxy.ts` currently drops most image generation options (quality, format, compression, background, moderation, imageSize, personGeneration). These options are configured in `images.ts` per context but never reach the edge function. This task expands the `ImageGenerationOptions` interface and updates `generateImage` to forward all options through `callAIProxy`.

Output: Updated `aiProxy.ts` with full option forwarding and unit tests proving all options pass through.
</objective>
