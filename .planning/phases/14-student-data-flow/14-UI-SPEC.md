## Data Contract Changes

These are the non-visual contracts that this phase must enforce:

### 1. Error Pattern Card ID
- **Before:** `temp_${Date.now()}` -- orphaned, never matches real cards
- **After:** Use nullable cardId (`null` when card not yet saved) or defer recording until card is saved
- **Consumer impact:** ErrorDashboard queries by cardId must handle null

### 2. Review Persistence
- **Before:** Reviews pushed to local array only, lost on refresh
- **After:** Reviews persisted to `card_reviews` Supabase table via updateCard()
- **Consumer impact:** ReviewPage loads reviews from DB instead of relying on in-memory array

### 3. Weak Area Filtering
- **Before:** `getCardsForWeakArea()` returns all low-scoring cards regardless of category
- **After:** Filter cards by error category matching
- **Consumer impact:** ErrorDashboard recommendations become category-relevant

### 4. Trail Gamification
- **Before:** Trail step completion awards no XP
- **After:** Award XP (amount TBD by planner, consistent with existing XP_PER_* constants)
- **Consumer impact:** XP counter updates after trail step completion
