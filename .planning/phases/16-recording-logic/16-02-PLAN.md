   useEffect(() => {
     return () => {
       // Revoke blob URL on unmount to prevent memory leak

   }, []);

5. **Add stream safety net in stopRecording**: In the `stopRecording` callback (lines 66-69), after calling `mediaRecorderRef.current.stop()`, also stop the stream tracks immediately:
   ```typescript
   const stopRecording = useCallback(() => {
     if (mediaRecorderRef.current && state.isRecording) {
       // Safety net: stop stream tracks immediately in case onstop doesn't fire
       // (e.g., if MediaRecorder was already inactive)
       const stream = mediaRecorderRef.current.stream;
       if (stream) {
         stream.getTracks().forEach(t => t.stop());
       }
       mediaRecorderRef.current.stop();
     }
   }, [state.isRecording]);
   ```

   Note: The existing `onstop` handler also calls `stream.getTracks().forEach(t => t.stop())` (line 52). The duplicate call is harmless (calling stop() on an already-stopped track is a no-op per spec) and ensures cleanup even if onstop never fires.
