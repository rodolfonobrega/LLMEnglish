## Phase Scope: Visual Impact Assessment

This phase has **zero visual impact**. All changes are:

1. **Hook cleanup** -- add `useEffect` cleanup to `useAudioRecorder.ts` to revoke blob URLs on unmount (internal memory fix)
2. **Service fix** -- add PCM clamping to `geminiLive.ts` `createPcmBlob` (internal audio quality fix)
3. **AudioWorklet migration** -- re-apply Phase 11's migration of both `geminiLive.ts` and `openaiRealtimeLive.ts` from `ScriptProcessorNode` to `AudioWorkletNode` (internal performance fix)
4. **Type fix** -- update `ReviewPage.tsx` `handleAudioReady` to accept `(blob: Blob, base64: string)` (internal type consistency)
5. **Stream cleanup** -- add explicit stream track cleanup in `stopRecording` as safety net (internal robustness)
6. **Tests** -- add `useAudioRecorder.test.ts`, update `geminiLive.test.ts` for AudioWorklet mocks

None of these changes alter rendering, layout, colors, typography, spacing, or user-visible text.
