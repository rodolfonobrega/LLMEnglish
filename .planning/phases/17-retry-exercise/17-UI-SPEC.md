## Interaction Contract

### Post-Exercise Button Group Layout

```
+------------------------------------------+
|  [Existing exercise card with prompt]    |
|  [Existing EvaluationResults component]  |
|                                          |
|  +--------------------------------------+|
|  |  RotateCcw  Tentar Novamente         ||  <- primary (teal), full-width
|  +--------------------------------------+|
|  +--------------------------------------+|
|  |  RefreshCw  Novo Exercicio           ||  <- secondary (white+border), full-width
|  +--------------------------------------+|
|  +--------------------------------------+|
|  |  ChevronLeft  Voltar ao Hub          ||  <- ghost (transparent), full-width
|  +--------------------------------------+|
+------------------------------------------+
```

**Button group container:** `div` with `className="space-y-3"` (12px gap between buttons).

**Button styling:** All three use `size="lg"` and `className="w-full rounded-2xl cursor-pointer"`.

### State Transitions

```
[Exercise Active (recording)] --> [Evaluation Results]
                                        |
                    +-------------------+-------------------+
                    |                   |                   |
              "Tentar Novamente"  "Novo Exercicio"   "Voltar ao Hub"
                    |                   |                   |
                    v                   v                   v
           [Exercise Active]    [Setup Step]         navigate('/practice')
           (same prompt,        (full reset)         (exit to hub)
            fresh recorder)
```

### Retry Behavior (ExerciseMode and ImageMode)

1. User clicks "Tentar Novamente"
2. `retrySame()` executes: sets `evaluation` to null, `error` to null, `saved` to false, `userAudioBase64` to null
3. Prompt/image/question state is preserved
4. Component re-renders into the "active session" branch (no evaluation = show recorder)
5. AudioRecorder unmounts from evaluation branch and remounts fresh in active branch
6. User sees the same exercise prompt with a fresh recorder

### Retry Behavior (LiveRoleplay via ConversationAnalysis)

1. User clicks "Tentar Novamente"
2. `onRetry` callback executes: sets `turns` to empty array, sets `phase` to 'conversation'
3. `scenario` is preserved
4. LiveSession reconnects with the same scenario prompt
5. User re-enters the live conversation
