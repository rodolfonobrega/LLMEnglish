<objective>
Fix the SM-2 algorithm to use three quality tiers and make new cards immediately reviewable.

Purpose: The current two-tier system treats scores 3-4/10 as "incorrect," causing a punitive full reset of learning progress. New cards also lack nextReviewAt, so they never appear in the review queue. These are the two most critical bugs in the review system.

Output: Modified `spacedRepetition.ts` with three-tier algorithm and immediate availability, plus new test file covering both changes.
</objective>
