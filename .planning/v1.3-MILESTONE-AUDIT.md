### Cross-Phase Integration Issues

#### ISSUE 1: 999.1 — exercise_ IDs not at call site (major)
- **From:** Phase 14 errorAnalysis.ts (extractErrorPatterns)
- **To:** Phase 17 ExerciseMode.tsx (retry generates new temp_ key)
- **Impact:** Error patterns accumulate by `temp_<timestamp>` per evaluation, not by exercise session. Retrying generates a different key — patterns are fragmented rather than grouped.
- **Fix:** Change ExerciseMode.tsx line 184 from `temp_${Date.now()}` to `exercise_${Date.now()}`

#### ISSUE 2: 999.2 — category filter is a no-op (major)
- **From:** Phase 14 promise (categoryToCardThemes in errorAnalysis.ts)
- **Impact:** Weak area card recommendations ignore error category — all users see same low-scoring cards regardless of which error type they need to practice.
- **Fix:** Implement categoryToCardThemes mapping and filter in getCardsForWeakArea()

#### ISSUE 3: TTS MIME type drift (minor — pre-existing, not v1.3)
- **Files:** ConversationAnalysis.tsx:21, src/hooks/useTTS.ts:9
- **Issue:** `config.ttsProvider` checked instead of `config.ttsSource` — always undefined, always returns `audio/wav`. Breaks OpenAI TTS (MP3 format) silent audio.
- **Not introduced by v1.3** but affects users in OpenAI TTS mode.
